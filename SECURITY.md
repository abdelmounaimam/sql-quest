# Security policy

SQL Quest runs learner SQL inside the browser (PGlite in a Web Worker), never on the server. The server only stores anonymous profiles and progress in SQLite.

If you find a vulnerability (for example a way to read or alter another player's data, or to execute code on the server), please report it privately through [GitHub security advisories](https://github.com/abdelmounaimam/sql-quest/security/advisories/new) instead of opening a public issue. You will get an answer within a week.
